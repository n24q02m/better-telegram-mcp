## 2024-05-24 - Dynamic Form Field Label Consistency
**Learning:** When injecting dynamic form fields via JavaScript (like the OTP/2FA step inputs in `credential_form.py`), it's easy to overlook structural and visual consistency with statically rendered fields. Using generic classes like `form-title` instead of the semantic `field-label` inside a `field-group` container disrupts the visual hierarchy. Furthermore, forgetting to add the `required` attribute to dynamically generated mandatory inputs degrades the experience for screen-reader users, even if a visual "Required" badge is present.
**Action:** When creating dynamic form steps, always mirror the DOM structure and attributes of existing static fields. Specifically, ensure the `<label>` uses the `field-label` class and is placed inside the `field-group` alongside its input. Crucially, always apply the native `required` attribute to the input element if it's mandatory, complementing any visual `aria-hidden="true"` badges.
