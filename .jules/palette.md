## 2026-08-04 - Password Visibility Toggle Script Injection
**Learning:** Adding a password visibility toggle via string replacement (`html.replace("</body>", ...)` with raw JavaScript) works as a micro-UX enhancement but can be brittle and bloats Python files. A more maintainable approach would be updating the base template or utilizing an external JS file if possible. However, the pattern handles dynamic fields effectively through `MutationObserver`.
**Action:** When constrained to Python string manipulation for HTML modifications, minimize the injected script length. Prioritize native templating solutions (like Jinja or modifying the base HTML in `mcp-core`) for future implementations to keep changes small and maintainable.
